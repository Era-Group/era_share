This module sets the Saudi Riyal (SAR) currency symbol to the new symbol ()
automatically -- both when the module is installed and every time it is upgraded.
No manual step is required.

If you ever want to set it by hand, copy the symbol () and paste it in the currency
symbol field for the Saudi Riyal (SAR) currency in:
Accounting > Configuration > Accounting > Currencies.

The symbol is also shown in a copy-ready box on the module's description page
(Apps > SAR Symbol Font), so you can select and copy it from there.
