ERA Address Client

Client for ERA Address Lookup service via service.era.net.sa — looks up Saudi addresses by building number or coordinates.

نبذة عن الوحدة

يوفّر هذا الوحدة عميلًا مشتركًا للاتصال بخدمة ERA للعناوين عبر service.era.net.sa، مما يتيح البحث عن العناوين السعودية بالرقم البنائي أو الإحداثيات الجغرافية. تُستخدَم الوحدة كمكتبة مشتركة تعتمد عليها وحدات ERA الأخرى دون تكرار منطق الاتصال. يتم تخزين مفتاح API وعنوان الخدمة بأمان في معاملات النظام ومعالجة أخطاء الشبكة بشكل واضح.

🏠

Saudi Address Lookup

Query the ERA Address service to resolve building numbers into full Saudi postal addresses including district, city, and zip code.

📍

Coordinate-Based Search

Reverse-geocode GPS coordinates to retrieve the nearest registered Saudi address from the national address database.

🔗

ERA Service Integration

Connects to service.era.net.sa with configurable base URL and API key — settings stored securely in system parameters.

🔄

Reusable Client Library

Shared across ERA modules as a dependency — any module can call the address API without duplicating connection logic.

🛡️

Error Handling

Gracefully handles network errors, invalid inputs, and service timeouts with clear exception messages for developers.
