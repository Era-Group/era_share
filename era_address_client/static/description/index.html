ERA Address Client

عميل العنوان الوطني من ERA

Shared library connecting all ERA modules to the ERA Address Lookup REST API at service.era.net.sa. Resolve Saudi national addresses from a building number or GPS coordinates — once, consistently, across every module that depends on it.

مكتبة مشتركة تربط جميع وحدات ERA بـ واجهة برمجة البحث عن العناوين الوطنية على service.era.net.sa. حوّل رقم المبنى أو إحداثيات GPS إلى عنوان وطني سعودي مفصَّل — مرة واحدة لجميع الوحدات المعتمدة عليها.

🏠

Saudi Address Lookup

Sends a POST request to /address/lookup with the building number (رقم المبنى). The API response includes district (الحي), city (المدينة), zip code, street name, and building type. All returned fields are automatically mapped to the corresponding res.partner address fields when the lookup is triggered from a partner form, saving data-entry time and eliminating manual transcription errors.

البحث عن العنوان الوطني السعودي

يُرسل طلب POST إلى /address/lookup بـرقم المبنى، فيعيد الحي والمدينة والرمز البريدي واسم الشارع ونوع المبنى. تُعيَّن الحقول تلقائياً على res.partner عند استدعاء البحث من نموذج جهة الاتصال، مما يُلغي الإدخال اليدوي ويضمن دقة البيانات.

📍

Reverse Geocoding

Supply GPS latitude and longitude to AddressClient.reverse(lat, lng) and receive the nearest registered address in the Saudi National Address database. This is especially useful for field teams logging site visits on mobile devices — the app captures current GPS position and resolves the official address without requiring the user to type anything. The result is returned in the same structured format as a building-number lookup.

الترميز الجغرافي العكسي

أدخل خط العرض وخط الطول في AddressClient.reverse(lat, lng) للحصول على أقرب عنوان مسجَّل في قاعدة بيانات العنوان الوطني. مثالي لفرق الميدان التي تسجّل الزيارات عبر الجوال — يلتقط التطبيق الموقع الحالي ويُحوّله إلى عنوان رسمي دون أي إدخال يدوي.

🔗

Configurable Service Endpoint

The base URL and API key are stored as ir.config_parameter records — era_address.service_url and era_address.api_key. Administrators change them in Settings → Technical → System Parameters without any code deployment or server restart. This makes it straightforward to point all ERA modules at a staging endpoint during testing and switch to production with a single field update.

نقطة خدمة قابلة للتهيئة

يُخزَّن عنوان URL الأساسي ومفتاح API في معاملات النظام era_address.service_url وera_address.api_key. يغيّرها المسؤول من الإعدادات ← التقني ← معاملات النظام دون نشر كود أو إعادة تشغيل الخادم.

🔄

Reusable Dependency

Install era_address_client once, then any other ERA module simply adds it to depends in its manifest. That module immediately gains access to both AddressClient(env).lookup(building_no) and AddressClient(env).reverse(lat, lng) with zero additional configuration. The HTTP layer is implemented in exactly one place — bug fixes and API version upgrades propagate to all dependent modules automatically.

اعتمادية قابلة لإعادة الاستخدام

ثبّت era_address_client مرة واحدة، ثم تُضيف أي وحدة ERA اسمها في depends للحصول فوراً على lookup وreverse. طبقة HTTP موحَّدة في مكان واحد — الإصلاحات وتحديثات الإصدار تنتشر تلقائياً لجميع الوحدات المعتمدة.

🛡️

Structured Error Handling

Network timeouts, 4xx client errors, 5xx server errors, and malformed JSON responses each raise a distinct typed Python exception — AddressLookupError, AddressNetworkError, and AddressParseError. Calling modules catch these at the form level and surface clean, user-readable validation messages rather than raw stack traces. This keeps the Odoo UI professional even when the external service is temporarily unavailable.

معالجة أخطاء منظَّمة

تُثار استثناءات Python مكتوبة بدقة لكل حالة: انتهاء مهلة الشبكة، أخطاء 4xx و5xx، وردود JSON مشوَّهة. تُعرض رسائل خطأ واضحة للمستخدم بدلاً من سجلات خام، مما يحافظ على احترافية واجهة أودو حتى عند توقف الخدمة الخارجية مؤقتاً.

⚡

Lightweight & Fast

No heavy third-party dependencies — the client uses Odoo's built-in requests session with a configurable timeout controlled by era_address.timeout. The design targets real-time use inside onchange handlers on partner and sales order forms, so latency is minimised. Connection pooling is handled by the existing Odoo session, keeping memory overhead negligible even under concurrent usage.

خفيف وسريع

لا اعتماديات ثقيلة — يستخدم عميل أودو المدمج requests مع مهلة قابلة للتهيئة عبر era_address.timeout. مُصمَّم للاستخدام الفوري داخل معالجات onchange، مع تجميع اتصالات يُدار بواسطة الجلسة الحالية لأودو للحفاظ على أداء ممتاز.

How it works

  1. Install ERA Address Client (or it installs automatically as a dependency).
  2. Go to Settings → Technical → System Parameters and set era_address.service_url and era_address.api_key.
  3. Any ERA module in its Python code calls AddressClient(self.env).lookup(building_no) or .reverse(lat, lng).
  4. The client posts to the ERA Address API, parses the response, and returns a structured dict of address fields — ready to write to res.partner.

كيف يعمل

  1. ثبّت ERA Address Client (أو يُثبَّت تلقائياً كاعتمادية).
  2. اذهب إلى الإعدادات ← التقني ← معاملات النظام وعيّن era_address.service_url وera_address.api_key.
  3. تستدعي أي وحدة ERA في كودها البرمجي AddressClient(self.env).lookup(building_no) أو .reverse(lat, lng).
  4. يُرسل العميل الطلب لواجهة ERA، يُحلّل الرد، ويُعيد قاموس بيانات العنوان جاهزاً للكتابة في res.partner.

🔑 Subscription Required

Requires an active ERA Address API subscription at service.era.net.sa. The API key is stored encrypted in Odoo system parameters and is never written to logs, chat history, or error messages. Contact your ERA account manager to obtain credentials.

يتطلب اشتراكاً نشطاً في ERA Address API على service.era.net.sa. يُخزَّن مفتاح API مشفَّراً في معاملات النظام ولا يُكتب في السجلات أو رسائل الخطأ. تواصل مع مدير حساب ERA للحصول على بيانات الاعتماد.

ℹ️ Developer Library — No UI

This module has no menus, views, or user-facing screens. It is a pure Python library intended to be consumed by other ERA modules. End users interact with address resolution through the UI of whichever ERA module depends on it, such as the partner form or sales order.

هذه الوحدة بلا قوائم أو نماذج أو شاشات للمستخدم. هي مكتبة Python خالصة مُصمَّمة للاستهلاك من وحدات ERA الأخرى. يتفاعل المستخدمون مع البحث عن العنوان من خلال واجهة الوحدة المعتمدة عليها.
