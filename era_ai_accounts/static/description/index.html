Shared & personal accounts

One account for everyone, or per-user accounts. An owner plus an allow-list and record rules decide exactly who can use each one.

Dynamic model catalog

Models are synced per account — version-proof aliases for the CLI, and a live /models pull for key accounts. No hard-coded model lists.

🔐

Encrypted & access-controlled

API secrets are Fernet-encrypted at rest and restricted to AI Account Managers. Shared users get a relation to the account, never the key.

Gentle on your account

One CLI call at a time across all workers and users, plus a gap that grows with the request size — bigger requests wait longer. With an instant kill switch and pre-use validation, the subscription is never hammered.

How it works

  1. Open AI ▸ AI Accounts and create an account — pick a provider and an auth mode (Local CLI proxy or API key).
  2. Click Validate connection, then Sync models.
  3. Set the scope (shared / personal), the owner and the allowed users.
  4. On any AI Agent, choose the AI Account and model — responses now run through it.

🪶 Gentle on your connected account

  • One call at a time, host-wide. A global lock (one pool per provider) guarantees at most one CLI call runs at any instant across every Odoo worker and user — the connected subscription never receives concurrent requests.
  • Size-aware pacing. Consecutive calls are separated by a gap that scales with the request body size (small chats ≈ 1 s, large contexts up to 30 s) — bigger requests wait longer.
  • Crash-safe & tunable. The lock auto-releases if a worker dies (no deadlocks), and every threshold is a live ir.config_parameter (ai.cli_min_gap, ai.cli_gap_per_kb, ai.cli_max_gap, ai.cli_lock_wait).
  • استدعاء واحد في كل مرة على مستوى الخادم. قفل عام يضمن تشغيل استدعاء واحد فقط لواجهة Claude في أي لحظة عبر جميع عمّال أودو وكل المستخدمين — فلا تصل أي طلبات متزامنة إلى الاشتراك.
  • مباعدة حسب الحجم. تُفصل الاستدعاءات المتتالية بفجوة زمنية تكبر مع حجم الطلب (المحادثات الصغيرة ≈ ثانية واحدة، والسياقات الكبيرة حتى 30 ثانية) — كلما كبر الطلب طال الانتظار.
  • آمن عند الأعطال وقابل للضبط. يتحرّر القفل تلقائيًا إذا توقّف أحد العمّال (بلا تجمّد)، وكل العتبات معاملات ir.config_parameter يمكن ضبطها مباشرةً.

⚖️ Used responsibly

The CLI proxy invokes the sanctioned first-party tool; it never replays OAuth tokens to the raw API. Serving many users from one subscription draws on its rate limits — so calls are globally serialized (one at a time) and paced by request size, with an instant kill switch.

ℹ️ Good to know (v1)

The CLI proxy is for chat / RAG agents; tool-driven "Ask AI" navigation needs an API-key account. Claude has no embeddings, so RAG keeps using the agent's standard embedding provider.
