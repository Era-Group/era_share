ERA AI Accounts

حسابات الذكاء الاصطناعي من ERA

Power Odoo 19 AI with linked provider accounts — run Claude or ChatGPT through their CLI (no API key, no per-token billing), or connect any provider by key and share each account with the right users.

شغّل ميزات الذكاء الاصطناعي في أودو 19 عبر حسابات مزوّدين مرتبطة — استخدم Claude أو ChatGPT من واجهة الأوامر دون مفتاح API ودون فوترة، أو اربط أي مزوّد بمفتاح وشارك كل حساب مع المستخدمين المناسبين.

🔌

Claude & ChatGPT — no API billing

Routes chat through the locally-authenticated claude or codex CLI. The first-party tool makes the call under its own auth — credentials are never read or replayed by Odoo.

Claude وChatGPT — بلا فوترة API

يمرّر المحادثات عبر واجهة claude أو codex المُسجَّل دخولها محلياً. الأداة الأصلية تُجري الاستدعاء بصلاحياتها — أودو لا تقرأ بيانات الاعتماد أو تُعيد استخدامها أبداً.

🧩

Every major provider

OpenAI, Google Gemini, Anthropic (native Messages API), Cloudflare Workers AI, and any OpenAI-compatible gateway (OpenRouter, Groq, Together, local) — connected by API key.

جميع المزوّدين الرئيسيين

OpenAI وGoogle Gemini وAnthropic وCloudflare Workers AI وأي بوابة متوافقة مع OpenAI (OpenRouter، Groq، Together، محلية) — تتصل بمفتاح API.

🎨

Text & image generation

Any module calls generate_text() / generate_image() on an account — images via Cloudflare FLUX 1/2 & SDXL (free daily Neurons) or OpenAI gpt-image-1 / DALL·E 3.

توليد النص والصور

أي وحدة تستدعي generate_text() أو generate_image() مباشرة — الصور عبر Cloudflare FLUX 1/2 (مجاني يومياً) أو OpenAI gpt-image-1 / DALL·E 3.

🔗

Login with Claude / Connect ChatGPT

Link a Claude subscription (OAuth) or a ChatGPT account via device code — like signing in on a TV: open a URL, type a short code, approve. Done once, in-app. No API key needed.

تسجيل دخول Claude / ربط ChatGPT

اربط اشتراك Claude (OAuth) أو ChatGPT عبر رمز الجهاز — مثل تسجيل الدخول على التلفاز: افتح رابطاً، اكتب رمزاً قصيراً، وافق. مرة واحدة داخل التطبيق. بلا مفتاح API.

🛠️

Agent tools — "Ask AI" works

CLI accounts run Odoo's agent tools (Ask AI database lookups, read_group, search…) through a strict JSON tool-call loop. Tools execute in Odoo with the asking user's own access rights.

أدوات الوكيل — "اسأل الذكاء الاصطناعي" تعمل

تُشغّل حسابات CLI أدوات وكيل أودو (استعلامات قاعدة البيانات، read_group، search…) عبر حلقة JSON صارمة. الأدوات تعمل في أودو بصلاحيات المستخدم الطالب نفسه.

👥

Shared & personal accounts

One account for everyone, or per-user accounts. An owner plus an allow-list and record rules decide exactly who can use each account.

حسابات مشتركة وشخصية

حساب واحد للجميع أو حسابات لكل مستخدم. يتحكم مالك الحساب وقائمة المسموح لهم وقواعد السجلات في تحديد من يستطيع استخدام كل حساب بالضبط.

🔄

Dynamic model catalog

Models are synced per account — version-proof aliases for CLI accounts and a live /models pull for key accounts. No hard-coded model lists anywhere.

كتالوج النماذج الديناميكي

تتزامن النماذج لكل حساب — أسماء مستعارة مقاومة للإصدارات لحسابات CLI وسحب مباشر من /models لحسابات المفاتيح. بلا قوائم نماذج مُرمَّزة.

🔐

Encrypted & access-controlled

API secrets are Fernet-encrypted at rest and restricted to AI Account Managers. Shared users get a relation to the account, never the raw key.

مشفَّرة ومحكومة الوصول

أسرار API مشفَّرة بـ Fernet وتقتصر على مديري حسابات AI. المستخدمون المشتركون يحصلون على ربط بالحساب — المفتاح لا يُكشف لهم أبداً.

🪶

Gentle on your account

One CLI call at a time across all workers and users, plus a gap that grows with request size (small chats ≈ 1 s, large contexts up to 30 s). Kill switch + pre-use validation included.

لطيف مع اشتراكك

استدعاء واحد في كل مرة على مستوى جميع العمّال والمستخدمين، مع مباعدة تكبر مع حجم الطلب (المحادثات الصغيرة ≈ ثانية، السياقات الكبيرة حتى 30 ثانية). يشمل مفتاح إيقاف فوري وتحقق قبل الاستخدام.

How it works

  1. Open AI ▸ AI Accounts and create an account — pick a provider and auth mode (Local CLI proxy or API key).
  2. Click Validate connection, then Sync models.
  3. Set the scope (shared / personal), the owner, and the allowed users.
  4. On any AI Agent, choose the AI Account and model — responses now run through it.

كيف يعمل

  1. افتح AI ▸ حسابات AI وأنشئ حساباً — اختر المزوّد ونمط المصادقة (CLI محلي أو مفتاح API).
  2. اضغط التحقق من الاتصال، ثم مزامنة النماذج.
  3. حدّد النطاق (مشترك / شخصي) والمالك والمستخدمين المسموح لهم.
  4. في أي وكيل AI، اختر حساب AI والنموذج — الردود ستعمل عبره الآن.

🪶 Gentle on your connected account  ·  لطيف مع اشتراكك

  • One call at a time, host-wide. A global lock (one pool per provider) guarantees at most one CLI call runs at any instant across every Odoo worker and user — the connected subscription never receives concurrent requests.
  • Size-aware pacing. Consecutive calls are separated by a gap that scales with request body size (small chats ≈ 1 s, large contexts up to 30 s) — bigger requests wait longer.
  • Crash-safe & tunable. The lock auto-releases if a worker dies, and every threshold is a live ir.config_parameter (ai.cli_min_gap, ai.cli_gap_per_kb, ai.cli_max_gap, ai.cli_lock_wait).
  • استدعاء واحد في كل مرة على مستوى الخادم. قفل عام يضمن تشغيل استدعاء CLI واحد فقط في أي لحظة عبر جميع عمّال أودو والمستخدمين — لا طلبات متزامنة تصل للاشتراك.
  • مباعدة حسب الحجم. الاستدعاءات المتتالية تفصلها فجوة تكبر مع حجم الطلب (المحادثات الصغيرة ≈ ثانية، السياقات الكبيرة حتى 30 ثانية) — كلما كبر الطلب طال الانتظار.
  • آمن عند الأعطال وقابل للضبط. يتحرّر القفل تلقائياً إذا توقّف عامل، وكل العتبات معاملات ir.config_parameter يمكن تعديلها مباشرة.

⚖️ Used responsibly

The CLI proxy invokes the sanctioned first-party tool and never replays OAuth tokens to the raw API. Calls are globally serialised and paced by size, with an instant kill switch.

يستدعي الوكيل الأداة الأصلية المعتمدة ولا يُعيد استخدام رموز OAuth أبداً. الاستدعاءات مُتسلسلة عالمياً ومُباعدة حسب الحجم مع مفتاح إيقاف فوري.

ℹ️ Good to know

CLI accounts support chat, RAG and agent tools. They are text-only: no embeddings (RAG keeps the agent's standard embedding provider) and no image generation — use a Cloudflare or OpenAI key account for images.

حسابات CLI تدعم الدردشة وRAG وأدوات الوكيل. نصوص فقط: بلا تضمينات (RAG يستخدم مزوّد التضمين المعياري للوكيل) وبلا توليد صور — استخدم حساب Cloudflare أو مفتاح OpenAI للصور.
