ERA AI Client Module

Shared internal AI client library used by other ERA modules to call configured AI providers — not user-facing, for developers.

نبذة عن الوحدة

وحدة ERA AI Client هي مكتبة داخلية مشتركة تستخدمها وحدات ERA الأخرى للاتصال بمزوّدي الذكاء الاصطناعي المُهيَّئين. تُجرِّد الفوارق بين المزوّدين المختلفين وتوفّر واجهة موحّدة لإرسال الطلبات واستقبال الردود. هذه الوحدة موجّهة للمطوّرين وليست واجهة مستخدم نهائي.

🧩

Shared AI Client

A common library module that other ERA add-ons depend on to call AI providers — centralizes provider connection logic in one place.

⚙️

Provider Abstraction

Abstracts away differences between AI providers so dependent modules call a unified interface regardless of backend.

🔑

Secure Key Management

API keys and provider settings are retrieved from system parameters — never hard-coded in module logic.

📦

Dependency Base

Install once and all ERA AI modules inherit the connection — reduces setup overhead for developers deploying multiple ERA modules.

🛠️

Developer-Focused

Not user-facing; designed for ERA module developers who need a consistent, tested way to reach AI endpoints from Odoo.
