# وحدة الالتزام — Compliance

**الإصدار:** 19.0.1.0.0 · **الجزء من:** Era Group CRM AI Agents · **يعتمد على:** `era_crm_ai_agents_base`

طبقة الحماية التي تمرّ عليها كل رسالة قبل ما تُرسل لعميلك. تضمن لك تلقائيًا:

- ✅ **موافقة العميل** قبل أي رسالة تسويقية (التزامًا بنظام حماية البيانات السعودي PDPL)، مع إلغاء اشتراك خلال 72 ساعة، وتنفيذ طلبات حقوق العميل (DSAR).
- 🕌 **التوقيت المناسب**: يوقف الإرسال وقت الصلاة، صلاة الجمعة، ساعات رمضان، نهاية الأسبوع، وخارج الدوام — بأوقات الصلاة الحقيقية حسب مدينة كل عميل.
- 💬 **الأسلوب اللائق**: يتأكد أن الرسالة فيها تحية ولقب مناسب ونبرة محترمة.

كل القواعد **قابلة للتعديل** من شاشة إعدادات واحدة، ولها مفاتيح تشغيل/إيقاف — بدون أي برمجة.

## أين أجد الوحدة في النظام؟

كل الشاشات تحت قائمة واحدة (تظهر لمن لديه صلاحية *AI Agents Manager*):

**CRM AI Agent Base → الإعدادات (Configuration)**

| المدخل | الوظيفة |
|---|---|
| **Compliance Settings** | ضبط كل القواعد (الصلاة، الدوام، الأسلوب، الموافقة…) |
| **Norm Vocabulary** | تعديل كلمات التحية والألقاب |
| **Consent Log** | سجل موافقات العملاء |
| **Compliance Status** | لوحة حالة الموافقات |
| **DSAR Requests** | تنفيذ طلبات حقوق العميل |
