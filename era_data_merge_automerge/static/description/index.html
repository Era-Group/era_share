How it works

  1. Turn on Data Cleaning and this add-on from Apps — one minute, done.
  2. Your duplicates are found and grouped for you, automatically.
  3. Skim the list and approve the ones you want gone.
  4. Sit back — every approved duplicate merges away on its own.
  5. Open the history anytime and see exactly what was cleaned.

كيف يعمل

  1. فعّل تنظيف البيانات وهذه الإضافة من التطبيقات — دقيقة واحدة تكفي.
  2. تُكتشف تكراراتك وتُجمَّع لك تلقائياً.
  3. تصفّح القائمة ووافق على ما تريد التخلص منه.
  4. استرخِ — كل تكرار معتمد يُدمَج من تلقاء نفسه.
  5. افتح السجل متى شئت لترى بالضبط ما جرى تنظيفه.

💡 Tip — Preview Before You Go Live  ·  عاين قبل التشغيل الفعلي

First time? Turn on preview and let it run once. You'll see every merge it would make — which records go, which one wins — before a single thing changes. Happy with what you see? Go live. Want an extra safety net? Start small on the first real run, then scale up the moment you trust it — and enjoy never cleaning by hand again.
