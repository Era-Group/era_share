ERA Filestore Cleanup

Automated cleanup of old PDF attachments in Odoo

تنظيف تلقائي لملفات PDF القديمة في أودو

العربية English
وحدة مُصممة لتنظيف مخزن أودو من ملفات PDF القديمة التي تم إنشاؤها تلقائيًا، مما يُقلل من استهلاك التخزين ويزيد من أداء قاعدة البيانات. A module designed to clean up Odoo's filestore from automatically generated old PDF files, reducing storage usage and improving database performance.

🚀 لماذا تُستخدم هذه الوحدة؟

  • تقليل استهلاك التخزين — تُحذف ملفات PDF القديمة تلقائيًا.
  • تحسين أداء قاعدة البيانات — من خلال تقليل عدد الملفات المخزنة.

🚀 Why Use This Module?

  • Reduce storage consumption — old PDF files are automatically deleted.
  • Improve database performance — by reducing the number of stored files.

🔧 الميزات الرئيسية

  • تنظيف تلقائي كل ساعة.
  • إبقاء الملفات التي قام المستخدم بتحميلها أو توقيعها.
  • منع التنفيذ المتزامن على عدة عملاء.
  • قابلة للتكوين لتحديد النماذج التي تُنشئ PDF.

🔧 Key Features

  • Automatic hourly cleanup.
  • Preserves user-uploaded or signed files.
  • Prevents concurrent execution on multiple workers.
  • Configurable models that generate PDFs.

📈 الفوائد

  • تقليل استهلاك التخزين بشكل تلقائي.
  • تحسين أداء قاعدة البيانات.
  • لا يتطلب أي تدخل يدوي.
  • سهلة التفعيل من واجهة التطبيقات.

📈 Benefits

  • Automatic storage reduction.
  • Improved database performance.
  • No manual intervention required.
  • Easy to enable from the Apps interface.

⚙️ التثبيت والإعداد

ضع الوحدة في دليل addons الخاص بأودو وقم بالترقية:

$ ./odoo-bin -u era_filestore_cleanup

لا حاجة لتكوين إضافي.

⚙️ Installation & Setup

Place the module in your Odoo addons directory and upgrade:

$ ./odoo-bin -u era_filestore_cleanup

No additional configuration is required.
