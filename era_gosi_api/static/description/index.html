ERA GOSI API Integration

Interact with Saudi GOSI Engagement Deduction API — verify employee GOSI status and deductions

نظرة عامة

تربط هذه الوحدة أودو بواجهة برمجية لنظام التأمينات الاجتماعية السعودية (GOSI) للتحقق من حالة تسجيل الموظفين واستعلام اشتراكاتهم واستقطاعاتهم. تُستخدَم بيانات الاعتماد المخزّنة بأمان في معاملات النظام للمصادقة على الواجهة البرمجية. تعمل الوحدة كطبقة خدمة مشتركة يمكن لوحدات الرواتب والموارد البشرية الاستفادة منها.

Key Features

🏛️

GOSI API Integration

Connect to the Saudi GOSI Engagement Deduction API to programmatically retrieve employee social insurance status and deduction amounts.

✅

Employee Status Verification

Verify in real-time whether an employee is registered with GOSI and retrieve their current contribution and deduction status.

💰

Deduction Data

Fetch precise GOSI deduction figures for payroll processing — employee share, employer share, and total monthly contributions.

🔐

Secure Authentication

Authenticates with the GOSI API using securely stored credentials from Odoo system parameters — keys never appear in code.

🔄

Reusable Service Layer

Designed as a shared service module that HR and payroll modules can depend on for all GOSI API calls.
