ERA GOSI API Integration

تكامل واجهة GOSI من ERA

Integrate Odoo HR with the Saudi GOSI Engagement & Deduction API. Verify registration status, retrieve contribution deductions, and flag discrepancies — all from the employee form without leaving Odoo or accessing external portals.

يدمج أودو HR مع واجهة GOSI للاشتراكات والاستقطاعات. تحقق من حالة التسجيل، استرجع استقطاعات الاشتراكات، وأشر إلى التناقضات — كل ذلك من نموذج الموظف دون مغادرة أودو أو الدخول إلى البوابات الخارجية.

🏛️

GOSI Registration Verification

Queries the GOSI API using the employee's l10n_sa_iqama (IQAMA number) or ssnid (Saudi national ID) field stored on hr.employee. The API response returns the employee's registration status — active, inactive, or not found — which is written to a dedicated gosi_status field and displayed as a colour-coded badge. The field is indexed and filterable in the employee list view for bulk compliance checks.

التحقق من التسجيل في GOSI

يستعلم واجهة GOSI باستخدام رقم الإقامة أو الهوية الوطنية المخزَّن في hr.employee. تُكتب حالة التسجيل (نشط، غير نشط، غير موجود) في حقل gosi_status مخصص وتظهر كشارة ملوّنة. الحقل قابل للتصفية في عرض قائمة الموظفين لفحوصات الامتثال الجماعية.

💰

Deduction Retrieval

Fetches the current month's employee contribution amount and employer contribution amount from GOSI's deduction endpoint. Values are written to gosi_employee_deduction and gosi_employer_deduction fields on hr.employee and can be compared with the computed payroll deduction lines to catch discrepancies before payroll close. A mismatch warning banner appears if values differ beyond the configured tolerance.

استرجاع الاستقطاعات

يجلب مبلغ اشتراك الموظف ومبلغ اشتراك صاحب العمل للشهر الحالي ويكتبهما في حقلين مخصصين للمقارنة مع بنود استقطاع الرواتب. يظهر تنبيه تلقائي على النموذج عند وجود تناقض يتجاوز العتبة المُهيَّأة قبل إغلاق دورة الرواتب.

📋

Engagement Period Lookup

Retrieves the employee's GOSI engagement start date (gosi_engagement_start) and end date (gosi_engagement_end) from the GOSI engagement endpoint. These dates are cross-referenced with the employee's Odoo contract start date to verify registration predates employment, supporting Saudi Labour Law compliance audits and GOSI inspection responses.

استرجاع فترة الاشتراك

يسترجع تاريخ بدء وانتهاء اشتراك الموظف في GOSI. تُقارَن هذه التواريخ بتاريخ بدء عقد الموظف في أودو للتحقق من أن التسجيل سابق للتوظيف، مما يدعم تدقيقات الامتثال لنظام العمل السعودي والردود على فحوصات GOSI.

🔐

Secure API Authentication

GOSI API credentials (client ID and client secret) are stored as encrypted ir.config_parameter values under Settings → HR → GOSI Configuration and never displayed after saving. At call time the module posts to GOSI's OAuth2 token endpoint to obtain a short-lived bearer token which is used for the actual API request and then discarded — no long-lived tokens are cached in the database.

مصادقة API آمنة

تُخزَّن بيانات اعتماد GOSI API كقيم ir.config_parameter مشفَّرة ولا تظهر بعد الحفظ. عند كل استدعاء يُجلَب رمز OAuth2 قصير الأمد من نقطة نهاية التوكن ويُستخدم للطلب ثم يُتخلص منه — لا رموز طويلة الأمد في قاعدة البيانات.

🔄

Bulk Verification Action

A server action available from HR → Employees list view → Action → Verify GOSI allows batch-verifying multiple employees in one click. Results are written via a background cron queue to avoid blocking the UI during large batch operations. A chatter message is posted on each employee record when its verification completes, and a summary notification appears when the full batch is done.

إجراء التحقق الجماعي

يتيح إجراء الخادم التحقق من عدة موظفين دفعةً واحدة من قائمة الموظفين. تُكتب النتائج عبر قائمة انتظار في الخلفية لتجنب تجميد الواجهة. تُنشر رسالة في chatter كل موظف عند اكتمال تحققه ويظهر إشعار ملخص عند انتهاء الدفعة كاملة.

📊

Compliance Status Badge

A summary widget on the employee form's Private Information tab displays a green / amber / red badge based on the last GOSI check result, the gosi_last_check date (last successful API pull), and whether the fetched deduction amounts match the payroll lines. The badge refreshes automatically after each verification call without requiring a full page reload.

شارة حالة الامتثال

تعرض شارة ملوّنة (أخضر / أصفر / أحمر) في تبويب المعلومات الخاصة بناءً على آخر نتيجة تحقق وتاريخ آخر استعلام ناجح ومطابقة مبالغ الاستقطاع. تتحدث الشارة تلقائياً بعد كل استدعاء تحقق دون إعادة تحميل الصفحة.

How it works

  1. Enter GOSI API credentials under Settings → HR → GOSI Configuration (client ID + client secret).
  2. Open an employee form — ensure the IQAMA or national ID is filled in on the Private Information tab.
  3. Click Verify GOSI: module fetches an OAuth2 bearer token then calls the GOSI engagement and deduction endpoints.
  4. Results (status, deduction amounts, engagement dates) are written to the employee record and the badge updates instantly.
  5. Payroll team reviews mismatch warnings before running payroll close for the month.

كيف يعمل

  1. أدخل بيانات اعتماد GOSI API في الإعدادات → الموارد البشرية → إعداد GOSI.
  2. افتح نموذج الموظف — تأكد من إدخال رقم الإقامة أو الهوية الوطنية في تبويب المعلومات الخاصة.
  3. اضغط التحقق من GOSI: يجلب النظام رمز OAuth2 ثم يستدعي نقاط نهاية GOSI.
  4. تُكتب النتائج في سجل الموظف فوراً وتتحدث الشارة في الحال.
  5. يراجع فريق الرواتب أي تحذيرات تناقض قبل إغلاق دورة الرواتب الشهرية.

🔐 API Security Note

GOSI client secrets are stored encrypted and never exposed in the UI after saving. The OAuth2 token fetched per call is short-lived (typically 1 hour) and is not persisted to the database. Rotate credentials every 90 days per GOSI's published security policy.

أسرار GOSI مشفَّرة ولا تظهر في الواجهة بعد الحفظ. رمز OAuth2 المُجلَب لكل استدعاء قصير الأمد ولا يُخزَّن في قاعدة البيانات. جدّد بيانات الاعتماد كل 90 يوماً وفق سياسة أمان GOSI المنشورة.

ℹ️ Requirements

Requires an active GOSI API subscription obtained from the GOSI developer portal (gosi.gov.sa). Each employee must have their national ID or IQAMA number filled in on the Private Information tab before verification can run. The Payroll module is recommended for deduction comparison.

يتطلب اشتراكاً نشطاً في GOSI API من بوابة المطورين (gosi.gov.sa). يجب إدخال رقم الهوية الوطنية أو الإقامة لكل موظف قبل التحقق. يُوصى بتثبيت وحدة الرواتب لمقارنة الاستقطاعات.
