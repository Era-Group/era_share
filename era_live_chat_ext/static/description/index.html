ERA Live Chat Extensions

إضافات الدردشة المباشرة من ERA

Front-end and back-end patches for Odoo Live Chat on Arabic-language AI-agent sites. Hides the "Ask Human" escalation button, fixes RTL overflow in AI replies, forces correct font rendering, and adds an All Chat History admin menu — install and forget.

تصحيحات للواجهتين الأمامية والخلفية لدردشة أودو المباشرة على المواقع العربية التي تعمل بوكلاء الذكاء الاصطناعي. تخفي زر "اسأل بشرياً"، تصلح تدفق النص العربي الطويل، تضبط تصيير الخطوط، وتضيف قائمة سجل المحادثات للمسؤولين — ثبّت وانسَ.

🙈

Hide "Ask Human" Button

Odoo's AI live chat widget renders an "Ask Human" / "اسأل بشرياً" button when an AI chatbot is active, offering a human escalation path. This module injects a CSS rule into web.assets_frontend and a JS OWL patch that removes the button element from the DOM on widget mount. Visitors on AI-only sites never see an escalation option that no one will answer — eliminating dead-end UX and failed expectations.

إخفاء زر "اسأل بشرياً"

يحقن النظام قاعدة CSS وتصحيح OWL يزيل زر التصعيد من DOM عند تحميل ويدجت الدردشة. زوار المواقع التي تعتمد الذكاء الاصطناعي حصراً لا يرون خياراً للتصعيد لن يُجيب عليه أحد — مما يمنع تجربة المستخدم المنتهية بطريق مسدود.

↔️

RTL Overflow Fix

Long Arabic AI replies triggered a horizontal scroll bar inside the chat bubble because the widget's default white-space: nowrap was not overridden for RTL content. This module patches the SCSS bundle to enforce word-break: break-word and overflow-wrap: anywhere inside .o_mail_message_content when the page lang or dir is Arabic. The fix targets Arabic pages only — LTR sites are completely unaffected.

إصلاح تجاوز RTL

يُصحّح حزمة SCSS لإلزام word-break: break-word وoverflow-wrap: anywhere داخل .o_mail_message_content عند اكتشاف الصفحات العربية. يمنع ظهور شريط التمرير الأفقي في فقاعات الدردشة للردود العربية الطويلة دون أي تأثير على المواقع اللاتينية.

🤖

Full AI End-to-End

With the human escalation path removed and the RTL display fixed, the AI chatbot configured under Live Chat → Chatbots handles every visitor conversation from greeting to resolution. The widget remains fully branded — custom logo, primary colour, and welcome message — and AI responses stream naturally using Odoo's standard im_livechat.chatbot.script step flow without interruption.

تجربة ذكاء اصطناعي كاملة

مع إزالة مسار التصعيد البشري وإصلاح العرض العربي، يتولى الذكاء الاصطناعي كل محادثة من التحية حتى الحل. تبقى الويدجت بعلامتها التجارية الكاملة وتتدفق ردود الذكاء الاصطناعي بشكل طبيعي عبر تدفق Chatbot المعياري في أودو دون انقطاع.

🎨

Font Consistency

Forces the live chat widget to inherit the website's body font family (e.g. Tajawal, Cairo, IBM Plex Arabic) rather than falling back to the Odoo UI default (Roboto / Noto). Icon fonts (Font Awesome) are explicitly excluded from the override using a :not([class^="fa"]) selector so icon glyphs render correctly alongside Arabic text.

اتساق الخطوط

يجبر ويدجت الدردشة على توريث خط body الموقع (مثل Tajawal أو Cairo) بدلاً من خط أودو الافتراضي. خطوط الأيقونات (Font Awesome) مستثناة صراحةً بمحدد :not([class^="fa"]) حتى تظهر الأيقونات بشكل صحيح بجانب النص العربي.

📜

All Chat History Menu

Adds a backend menu item under Live Chat → All Chat History that lists every discuss.channel session linked to a live chat — including AI-only chatbot sessions that the default Live Chat app hides behind team-based filters. The list view shows visitor, channel name, chatbot script, message count, and session start time. No extra filter adjustment needed for full visibility.

قائمة سجل جميع المحادثات

تضيف عنصر قائمة الدردشة المباشرة → سجل جميع المحادثات يعرض كل جلسة discuss.channel المرتبطة بالدردشة المباشرة — بما فيها جلسات الذكاء الاصطناعي الحصرية التي تختبئ خلف فلاتر الفريق الافتراضية. يمنح مديري الدعم رؤية كاملة بدون ضبط إضافي.

🔧

Install and Forget

No settings page, no configuration required, no Odoo server restart needed. CSS and JS assets are automatically bundled into web.assets_backend and web.assets_frontend via standard ir.asset records declared in the module's data XML. On the next browser reload all patches are active for both frontend visitors and backend agents. Uninstalling cleanly removes every override.

ثبّت وانسَ

لا صفحة إعدادات ولا تهيئة ولا إعادة تشغيل خادم مطلوبة. تُضاف أصول CSS و JS تلقائياً عبر سجلات ir.asset المعيارية المُعلنة في XML الوحدة. عند أول تحميل للمتصفح تصبح جميع التصحيحات نشطة. إلغاء التثبيت يزيل كل التجاوزات نظيفاً.

How it works

  1. Install era_live_chat_ext alongside the standard im_livechat module from Apps.
  2. JS and SCSS assets are registered in web.assets_backend and web.assets_frontend — no manual inclusion needed.
  3. On the next browser page load, the "Ask Human" button is absent and RTL overflow is fixed for Arabic pages.
  4. Backend users see the new Live Chat → All Chat History menu with unfiltered session visibility.

كيف يعمل

  1. ثبّت era_live_chat_ext مع وحدة im_livechat المعيارية من التطبيقات.
  2. تُسجَّل أصول JS و SCSS في حزم الأصول المعيارية — لا إدراج يدوي مطلوب.
  3. عند أول تحميل للمتصفح، يختفي زر "اسأل بشرياً" ويُصلح تدفق النص العربي في الصفحات العربية.
  4. يرى مستخدمو الخلفية قائمة الدردشة المباشرة → سجل جميع المحادثات الجديدة بدون فلاتر.

ℹ️ Compatibility & Upgrade Safety  ·  التوافق وأمان الترقية

This module targets Odoo 19's im_livechat with the Chatbot AI agent feature. The "Ask Human" patch hooks into the LivechatButton OWL component by name. If Odoo changes the component name in a minor update, the JS patch degrades gracefully (no-op) rather than throwing an error — the site continues to work and the button may reappear until the patch is updated. No Python model monkey-patching is performed.

تستهدف هذه الوحدة im_livechat في أودو 19. تصحيح "اسأل بشرياً" يربط بمكوّن OWL LivechatButton بالاسم. إذا غيّرت أودو اسم المكوّن في تحديث طفيف، يتجاهل التصحيح بأمان دون رمي أخطاء — الموقع يستمر في العمل وقد يعود الزر حتى تحديث التصحيح. لا تعديل على نماذج Python الأساسية.
