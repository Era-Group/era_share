نظرة عامة

تُقدِّم هذه الوحدة تحسينات على واجهة الدردشة المباشرة في أودو، أبرزها إمكانية إخفاء زر "اسأل موظفًا" وإصلاح مشكلة التمرير الأفقي التي تظهر في ردود الذكاء الاصطناعي باللغة العربية. تعمل الإصلاحات بشكل غير تدخلي دون تعديل ملفات أودو الأساسية. تضمن الوحدة عرضًا سليمًا للنصوص العربية في واجهة الدردشة مع محاذاة RTL صحيحة.

Key Features

🙈

Hide 'Ask Human' Button

Optionally hide the 'Ask Human' escalation button in the AI live chat widget — keeps the interface clean when human handoff is not available or desired.

🔤

RTL Overflow Fix

Fixes a horizontal scrollbar bug that appears in Arabic AI chat responses due to RTL text direction — messages now display cleanly without overflow.

💬

Arabic Chat Polish

Ensures the live chat widget renders Arabic text correctly with proper RTL alignment and no layout artifacts.

🎨

Non-Invasive Patches

Applies targeted CSS and JS tweaks without modifying Odoo's live chat core — compatible with future live chat updates.
