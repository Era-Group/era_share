ERA Monte Carlo Simulation

Turn business uncertainty into actionable insight — run thousands of scenarios in the background and read the results as a plain-language risk summary. No Excel, no Python scripts, no statistics degree required.

حوّل حالة عدم اليقين في أعمالك إلى معرفة قابلة للتنفيذ. يتيح لك هذا الوحدة تشغيل آلاف السيناريوهات في الخلفية وقراءة النتائج كملخص مخاطر بلغة واضحة — دون إكسل ودون درجة في الإحصاء.

Key Features

🎲 Probability Distributions

Six distribution types: Fixed (no uncertainty), Uniform (equal probability between min and max), Normal (bell curve, defined by mean and std dev), Log-normal (skewed, for costs and durations), Triangular (min/mode/max — ideal for expert estimates), Discrete (explicit probability-weighted list of outcomes). Parameters are set in the Odoo form and validated before the simulation runs.

🎲 التوزيعات الاحتمالية

ستة أنواع: ثابت وموحد وطبيعي ولوغاريتمي طبيعي ومثلثي ومتقطع. كل معاملات التوزيع تُضبط في نموذج أودو وتُتحقق منها قبل بدء المحاكاة.

📊 Monte Carlo Engine

Runs N iterations (configurable, default 10,000) sampling each input independently. The engine is pure Python (NumPy) and executes in an Odoo cron job so the UI stays responsive. Progress is tracked in a simulation.run record; users can watch the iteration counter update live.

📊 محرك مونتي كارلو

يُشغّل N تكراراً (قابل للضبط، الافتراضي 10,000) يأخذ عينات من كل مدخل باستقلالية. المحرك بـ Python خالص (NumPy) وينفّذ في وظيفة مجدولة أودو. يتتبع التقدم في سجل simulation.run بعداد يُحدَّث لحظياً.

🗣️ Plain-Language Risk Summary

After the run the AI generates a 200-word plain-language interpretation: "There is a 75% chance that revenue exceeds SAR 1.2M; the most likely scenario is SAR 1.45M; the main risk driver is…". The summary is stored on the simulation record and can be regenerated at any time.

🗣️ ملخص المخاطر بلغة واضحة

بعد التشغيل يولّد الذكاء الاصطناعي تفسيراً بلغة بسيطة: "هناك 75% احتمال أن تتجاوز الإيرادات 1.2 مليون ريال؛ السيناريو الأكثر احتمالاً هو 1.45 مليون؛ المحرك الرئيسي للمخاطر هو…". يُخزَّن الملخص في السجل ويمكن إعادة توليده.

🤖 AI-Assisted Distribution Fitting

Click Ask AI on any input variable and describe it in plain English ("our project always takes 3–6 months, usually around 4"). The AI suggests the best distribution and parameters, which the user can accept with one click — no statistics knowledge needed.

🤖 ملاءمة التوزيع بمساعدة الذكاء الاصطناعي

اضغط "اسأل الذكاء الاصطناعي" على أي متغير مدخل وصِفه بلغة بسيطة. يقترح الذكاء الاصطناعي أفضل توزيع ومعاملاته، ويقبلها المستخدم بنقرة واحدة.

📈 Interactive Output Charts

Results displayed as: (a) histogram of outcomes, (b) cumulative probability curve showing P10/P50/P90, and (c) tornado chart ranking input variable impact. All charts are rendered as inline SVG inside the Odoo form — no external chart library, no JavaScript dependency.

📈 مخططات النتائج التفاعلية

تُعرض النتائج كـ: (أ) رسم بياني تكراري، (ب) منحنى احتمال تراكمي يُظهر P10/P50/P90، (ج) مخطط إعصار يُرتّب تأثير كل متغير. جميع المخططات SVG داخل نموذج أودو — بلا مكتبة رسوم خارجية.

🏗️ Safe Custom Formulas

Users write formulas linking input variables (e.g. revenue - fixed_cost - (variable_cost * units)). Formulas are evaluated in a sandboxed asteval environment — only arithmetic operations, no import, no file access.

🏗️ معادلات مخصصة آمنة

يكتب المستخدمون معادلات تربط المتغيرات. تُقيَّم في بيئة asteval معزولة — عمليات حسابية فقط، بلا import، بلا وصول للملفات.

📋 Simulation Model Library

Pre-built models for common use cases: Revenue Forecast, Cost Estimate, Project Duration, Break-Even Analysis. Users select a template and fill in their numbers — no need to build a model from scratch. All templates are fully editable and saveable as new models.

📋 مكتبة نماذج المحاكاة

نماذج جاهزة لحالات الاستخدام الشائعة: توقعات الإيرادات، تقديرات التكلفة، مدة المشروع، تحليل نقطة التعادل. يختار المستخدم قالباً ويملأ أرقامه دون الحاجة لبناء نموذج من الصفر.

🔁 Scenario Comparison

Save multiple simulation runs on the same model (e.g. "Optimistic 2026", "Base 2026", "Pessimistic 2026") and compare their P50 outcomes side-by-side in a dedicated comparison view. Ideal for presenting a range of outcomes to stakeholders.

🔁 مقارنة السيناريوهات

احفظ تشغيلات محاكاة متعددة على نفس النموذج وقارن نتائج P50 جنباً إلى جنب في عرض المقارنة.

⚙️ How it Works  |  كيف يعمل

  1. Open Monte Carlo → Simulation Models → New Model
  2. Add input variables with their probability distributions
  3. Define the output formula linking the variables
  4. Click Run Simulation (N iterations)
  5. Review histogram, P10/P50/P90, and AI plain-language summary
  6. Share or export the run record to stakeholders
  1. افتح مونتي كارلو ← نماذج المحاكاة ← نموذج جديد
  2. أضف متغيرات المدخلات بتوزيعاتها الاحتمالية
  3. عرِّف معادلة الناتج التي تربط المتغيرات
  4. اضغط تشغيل المحاكاة (N تكرار)
  5. راجع الرسم البياني وP10/P50/P90 وملخص الذكاء الاصطناعي
  6. شارك سجل التشغيل أو صدِّره للمعنيين

📐 Statistical Rigour, Zero Setup

Each output variable is automatically described by its mean, median, standard deviation, P10, P50, and P90. The module handles sampling, aggregation, and chart rendering — all a business user needs to do is describe their inputs and read the summary.

كل متغير ناتج يُوصف تلقائياً بمتوسطه ووسيطه وانحرافه المعياري وP10/P50/P90. الوحدة تتولى أخذ العينات والتجميع ورسم المخططات — كل ما يحتاجه المستخدم هو وصف مدخلاته وقراءة الملخص.
