Extend Odoo AI with a fully configurable custom LLM provider (OpenAI-compatible API)

نظرة عامة

تُضيف هذه الوحدة مزوّد ذكاء اصطناعي مخصص وقابل للتهيئة الكاملة إلى إطار عمل الذكاء الاصطناعي في أودو. يتوافق المزوّد مع أي واجهة برمجية متوافقة مع معيار OpenAI مثل OpenRouter وGroq وأي نموذج لغوي محلي. يظهر كمزوّد رسمي في قائمة مزوّدي الذكاء الاصطناعي ويعمل مع جميع ميزات الذكاء الاصطناعي في أودو.

Key Features

🔌

Custom LLM Provider

Add a fully configurable custom AI provider to Odoo's AI framework — connect any OpenAI-compatible API endpoint as a first-class Odoo AI provider.

🌐

OpenAI-Compatible

Works with any API that follows the OpenAI chat completions standard: OpenRouter, Groq, Together AI, local Ollama instances, and more.

⚙️

Fully Configurable

Set the base URL, API key, model name, and timeout from Odoo settings — no code changes needed to switch between different LLM backends.

🔗

Native Odoo Integration

Registered as a proper Odoo AI provider — appears in the AI provider dropdown and works with all Odoo AI features including Ask AI.

🛡️

Secure Credentials

API keys stored in encrypted system parameters — never exposed in logs or UI.
