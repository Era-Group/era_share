ERA Odoo AI Ext

Extend Odoo 19 AI with any OpenAI-compatible endpoint — Ollama, Azure, OpenRouter, Groq, or your own vLLM server — as a first-class provider. No core-file edits, no restarts, no compromises.

وسِّع ذكاء أودو 19 الاصطناعي بأي نقطة نهاية متوافقة مع OpenAI — Ollama أو Azure أو OpenRouter أو Groq أو خادمك الخاص — كمزوّد متكامل. دون تعديل ملفات النظام ودون إعادة تشغيل.

Key Features

🔌 Custom LLM Provider Type

Adds a custom_llm option to the Odoo AI provider selector (Settings → AI → Providers). When selected, three extra fields appear: Base URL, API Key (optional, stored encrypted), and Default Model. The provider appears in the same list as OpenAI and Gemini — no special Technical menu required.

🔌 نوع مزوّد LLM مخصص

يضيف خيار custom_llm إلى منتقي مزوّد AI في أودو. عند اختياره تظهر ثلاثة حقول إضافية: Base URL ومفتاح API (اختياري، مشفَّر) واسم النموذج الافتراضي. يظهر المزوّد في نفس قائمة OpenAI وGemini دون قائمة تقنية خاصة.

⚙️ Full Settings UI

All configuration lives in the standard Odoo AI settings page — no Technical menu required. Base URL, API key, and model name are editable by any user with the AI Configuration access right. Changes take effect immediately without a server restart.

⚙️ واجهة إعدادات كاملة

جميع الإعدادات في صفحة AI الاعتيادية في أودو دون الحاجة لقائمة تقنية. عنوان URL ومفتاح API واسم النموذج قابلة للتعديل فوراً دون إعادة تشغيل الخادم.

🔄 Chat, Tool-Call & Embedding Support

The custom provider intercepts Odoo's AI dispatch path for chat completions, agent tool-calls (JSON mode), and text embeddings (RAG). All three paths use the OpenAI-compatible request format, so any server that speaks /v1/chat/completions and /v1/embeddings works out of the box.

🔄 دعم الدردشة واستدعاءات الأدوات والتضمينات

يعترض المزوّد المخصص مسار إرسال AI في أودو للمحادثات واستدعاءات أدوات الوكيل (JSON mode) وتضمينات النص (RAG). الثلاثة مسارات تستخدم تنسيق OpenAI المتوافق.

🛡️ Non-Invasive Patch

Uses Python's module-level monkey-patch via post_load hook. Odoo's ai addon files are never touched — future Odoo updates install without conflicts. The patch is applied once at startup and reverts cleanly if the module is uninstalled.

🛡️ رقعة غير تدخلية

يستخدم monkey-patch على مستوى الوحدة عبر خطاف post_load. ملفات وحدة ai في أودو لا تُلمس أبداً — تحديثات أودو المستقبلية تُثبَّت دون تعارض. تُطبَّق الرقعة مرة واحدة عند البدء وتُزال نظيفاً عند إلغاء التثبيت.

🔑 Encrypted Key Storage

The API key is Fernet-encrypted in ir.config_parameter. It is never written to logs, never returned in RPC responses, and only decrypted at request time inside the provider adapter. Admins can rotate keys without restarting Odoo.

🔑 تخزين مشفَّر للمفتاح

مفتاح API مشفَّر بـ Fernet في ir.config_parameter. لا يُكتب في السجلات ولا يُعاد في ردود RPC، ويُفكَّ تشفيره فقط عند الطلب داخل محوّل المزوّد. يمكن للمسؤولين تدوير المفاتيح دون إعادة تشغيل أودو.

⚙️ How it Works  |  كيف يعمل

  1. Install the module from Odoo Apps
  2. Go to Settings → AI → Providers
  3. Select Custom LLM as the provider type
  4. Enter Base URL (e.g. https://openrouter.ai/api/v1) and API Key
  5. Enter model name (e.g. meta-llama/llama-3-70b-instruct)
  6. Click Test Connection
  7. All Odoo AI features (Ask AI, agents, RAG) now route through your endpoint

🔗 Works with Ollama, Azure, OpenRouter, Groq & more

Any server implementing the OpenAI REST spec works: Ollama for local models, Azure OpenAI for enterprise, OpenRouter for multi-model routing, Groq for ultra-fast inference, Together AI for open-weights models, or a corporate proxy enforcing your own access policies.

أي خادم يُنفّذ مواصفة OpenAI REST يعمل: Ollama للنماذج المحلية، Azure OpenAI للمؤسسات، OpenRouter لتوجيه النماذج المتعددة، Groq للاستدلال فائق السرعة، Together AI لنماذج الأوزان المفتوحة، أو وكيل مؤسسي يطبّق سياسات الوصول الخاصة بك.
