ERA PO Translator

Manage and edit PO translation files directly inside Odoo

No SSH access or external PO editors required. Translate any installed module from the comfort of the Odoo backend.

Key Features

Quick Translate Wizard

Start a translation session in seconds. Pick a module, choose source and target languages, and optionally auto-translate all terms in one click.

Background Auto-Translation

Translate hundreds or thousands of terms via Google Translate in the background. Live progress updates every 50 terms. Stop at any time with one click.

Inline Editing

Edit source text and translations directly in a spreadsheet-like list view. Color-coded rows show translated (green) vs. untranslated terms at a glance.

Translation Suggestions

Click "Suggest" on any term to get multiple translation alternatives. Pick the best one or type your own override.

Save & Import

Write translations back to the PO file and import into Odoo in one click. Works with both custom and standard modules. Code translation cache is automatically refreshed.

Rescan Source Code

Detect new translatable strings added to a module's source code since the last session. Only untranslated terms are added — existing work is preserved.

Progress Tracking & Chatter

Real-time progress bar with total, translated, and untranslated counts. Full mail thread support — background translation results, user actions, and notes are posted to the chatter for audit and collaboration.

Search, Filter & Group

Filter sessions by status (Draft / In Progress / Done). Group by module, target language, or status. Color-coded list view for quick session overview.

How to Use

  1. Enable Developer Mode — Go to Settings → General Settings → Developer Tools → Activate Developer Mode.
  2. Open PO Translator — Click the PO Translator app in the main Odoo app drawer, or navigate to PO Translator → Translation Sessions.
  3. Quick Translate — Click Quick Translate in the menu (or click New — it automatically opens the wizard). Select the module you want to translate, choose the source and target languages, and optionally check Auto-translate on start.
  4. Load PO File — If the session is new (draft), click Load / Reload PO File to import all terms from the module's existing PO file.
  5. Edit Translations — Click any row in the Translation Terms list to edit the translation inline. Use the Suggest button for AI-powered alternatives.
  6. Auto-Translate All — Click Auto-Translate All to translate every untranslated term via Google Translate in the background. Progress updates live. You can stop at any time with the Stop Translation button.
  7. Rescan Source — If the module has been updated since the session was created, click Rescan Source to detect and add any new untranslated strings.
  8. Save & Import — When satisfied, click Save & Import into Odoo to write the PO file to disk and load translations into the Odoo database.

Button Reference

Button When Available Description
Load / Reload PO File Draft state Imports all msgid/msgstr entries from the module's PO file. Creates the i18n directory if it does not exist.
Reload PO File In Progress / Done Re-imports the PO file, discarding any unsaved changes.
Rescan Source In Progress / Done Extracts a POT template from the module source and adds any new untranslated terms to the session.
Auto-Translate All In Progress / Done (not while translating) Queues all untranslated terms for background translation via Google Translate. Runs as a scheduled job — safe for large modules.
Stop Translation While background translation is running Gracefully stops the background translation. All terms translated so far are preserved.
Save & Import into Odoo In Progress / Done Writes the PO file to disk, imports translations into Odoo's database, and refreshes the code translation cache.
Reset to Draft In Progress / Done Returns the session to draft state.
Suggest (per term) Always Opens a modal with multiple translation suggestions for the selected term.

Requirements

  • Odoo 19.0 Community or Enterprise
  • Developer Mode must be enabled (Settings → Developer Tools)
  • deep-translator Python package (optional, for auto-translate and suggestion features): 
    pip install deep-translator
  • Administration / Settings access (users with the Settings privilege under Administration)

Standard vs. Custom Modules

Custom Modules Standard Odoo Modules
Load PO Reads from module i18n/ directory Reads from module i18n/ directory
Save & Import Writes PO file to disk + imports into DB Imports directly into DB (no file write — read-only filesystem)
Rescan Source Generates POT and writes to i18n/ Generates POT in a temp file (no filesystem changes)

Technical Notes

  • Background translation uses ir.cron one-shot jobs with a dedicated database cursor to avoid HTTP timeouts and cron lock conflicts.
  • Progress commits every 50 terms, with savepoint-based conflict handling for concurrent access.
  • After import, the in-memory CodeTranslations cache is invalidated so Python _() strings reflect new translations immediately (per worker).
  • PO entries include #. odoo-python comments required by Odoo 19's code translation loader.
  • The companion POT file is kept in sync to prevent PoFileReader from marking new entries as obsolete.

Included Translations

The module ships with a complete Arabic (ar) translation. Additional languages can be added by creating PO files in the i18n/ directory.

لا حاجة للوصول عبر SSH أو محررات PO خارجية. ترجم أي وحدة مُثبّتة من داخل واجهة أودو الخلفية بكل سهولة.

الميزات الرئيسية

معالج الترجمة السريعة

ابدأ جلسة ترجمة في ثوانٍ. اختر الوحدة، حدد لغة المصدر واللغة المستهدفة، ويمكنك اختيارياً ترجمة جميع المصطلحات تلقائياً بنقرة واحدة.

الترجمة التلقائية في الخلفية

ترجم مئات أو آلاف المصطلحات عبر Google Translate في الخلفية. تحديثات مباشرة للتقدم كل 50 مصطلح. أوقف في أي وقت بنقرة واحدة.

التحرير المباشر

حرّر النص المصدر والترجمات مباشرة في عرض قائمة يشبه جداول البيانات. صفوف ملونة تُظهر المصطلحات المترجمة (أخضر) وغير المترجمة بنظرة سريعة.

اقتراحات الترجمة

انقر على "اقتراح" لأي مصطلح للحصول على بدائل ترجمة متعددة. اختر الأفضل أو اكتب ترجمتك الخاصة.

الحفظ والاستيراد

اكتب الترجمات إلى ملف PO واستوردها في أودو بنقرة واحدة. يعمل مع الوحدات المخصصة والقياسية. يتم تحديث ذاكرة التخزين المؤقت لترجمات الكود تلقائياً.

إعادة فحص الكود المصدري

اكتشف النصوص القابلة للترجمة الجديدة المضافة إلى كود الوحدة منذ الجلسة الأخيرة. تُضاف فقط المصطلحات غير المترجمة — العمل الحالي محفوظ.

تتبع التقدم والمحادثات

شريط تقدم فوري مع عدد المصطلحات الإجمالية والمترجمة وغير المترجمة. دعم كامل لسجل المحادثات — نتائج الترجمة في الخلفية وإجراءات المستخدم والملاحظات تُنشر في المحادثة للمراجعة والتعاون.

البحث والتصفية والتجميع

صفّ الجلسات حسب الحالة (مسودة / قيد التنفيذ / مكتمل). جمّع حسب الوحدة أو اللغة المستهدفة أو الحالة. عرض قائمة ملونة لنظرة سريعة على الجلسات.

طريقة الاستخدام

  1. تفعيل وضع المطور — اذهب إلى الإعدادات → الإعدادات العامة → أدوات المطور → تفعيل وضع المطور.
  2. فتح مترجم PO — انقر على تطبيق PO Translator في درج التطبيقات الرئيسي، أو انتقل إلى PO Translator → جلسات الترجمة.
  3. الترجمة السريعة — انقر على ترجمة سريعة في القائمة (أو انقر جديد — يفتح المعالج تلقائياً). اختر الوحدة المراد ترجمتها، حدد لغة المصدر واللغة المستهدفة، ويمكنك اختيارياً تفعيل الترجمة التلقائية عند البدء.
  4. تحميل ملف PO — إذا كانت الجلسة جديدة (مسودة)، انقر تحميل / إعادة تحميل ملف PO لاستيراد جميع المصطلحات من ملف PO الحالي للوحدة.
  5. تحرير الترجمات — انقر على أي صف في قائمة مصطلحات الترجمة لتحرير الترجمة مباشرة. استخدم زر اقتراح للحصول على بدائل ذكية.
  6. ترجمة الكل تلقائياً — انقر ترجمة الكل تلقائياً لترجمة كل المصطلحات غير المترجمة عبر Google Translate في الخلفية. يتم تحديث التقدم مباشرة. يمكنك الإيقاف في أي وقت بزر إيقاف الترجمة.
  7. إعادة فحص المصدر — إذا تم تحديث الوحدة منذ إنشاء الجلسة، انقر إعادة فحص كود الوحدة لاكتشاف وإضافة أي نصوص جديدة غير مترجمة.
  8. الحفظ والاستيراد — عند الرضا عن الترجمات، انقر حفظ واستيراد إلى Odoo لكتابة ملف PO على القرص وتحميل الترجمات في قاعدة بيانات أودو.

مرجع الأزرار

الزر متى يظهر الوصف
تحميل / إعادة تحميل ملف PO حالة المسودة يستورد جميع إدخالات msgid/msgstr من ملف PO الخاص بالوحدة. ينشئ مجلد i18n إذا لم يكن موجوداً.
إعادة تحميل ملف PO قيد التنفيذ / مكتمل يعيد استيراد ملف PO مع تجاهل أي تغييرات غير محفوظة.
إعادة فحص كود الوحدة قيد التنفيذ / مكتمل يستخرج قالب POT من كود الوحدة ويضيف أي مصطلحات جديدة غير مترجمة إلى الجلسة.
ترجمة الكل تلقائياً قيد التنفيذ / مكتمل (ليس أثناء الترجمة) يضع جميع المصطلحات غير المترجمة في قائمة الانتظار للترجمة في الخلفية عبر Google Translate. يعمل كمهمة مجدولة — آمن للوحدات الكبيرة.
إيقاف الترجمة أثناء تشغيل الترجمة في الخلفية يوقف الترجمة في الخلفية بسلاسة. جميع المصطلحات المترجمة حتى الآن محفوظة.
حفظ واستيراد إلى Odoo قيد التنفيذ / مكتمل يكتب ملف PO على القرص، ويستورد الترجمات في قاعدة بيانات أودو، ويحدّث ذاكرة التخزين المؤقت لترجمات الكود.
إعادة إلى المسودة قيد التنفيذ / مكتمل يعيد الجلسة إلى حالة المسودة.
اقتراح (لكل مصطلح) دائماً يفتح نافذة تحتوي على اقتراحات ترجمة متعددة للمصطلح المحدد.

ملاحظات تقنية

  • تستخدم الترجمة في الخلفية مهام ir.cron لمرة واحدة مع مؤشر قاعدة بيانات مخصص لتجنب انتهاء مهلة HTTP وتعارضات قفل المهام المجدولة.
  • يتم حفظ التقدم كل 50 مصطلح، مع معالجة التعارضات عبر نقاط الحفظ للوصول المتزامن.
  • بعد الاستيراد، يتم إبطال ذاكرة التخزين المؤقت CodeTranslations في الذاكرة لتعكس سلاسل _() في بايثون الترجمات الجديدة فوراً (لكل عامل).
  • تتضمن إدخالات PO تعليقات #. odoo-python المطلوبة من محمّل ترجمات الكود في Odoo 19.
  • يتم الحفاظ على تزامن ملف POT المرافق لمنع PoFileReader من تصنيف الإدخالات الجديدة كمهملة.
