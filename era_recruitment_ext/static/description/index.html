ERA Recruitment AI Analyser

محلّل التوظيف بالذكاء الاصطناعي من ERA

Adds AI-powered CV match analysis to Odoo Recruitment. Upload a CV, click Analyse, and receive a numeric match score, a strengths-and-gaps breakdown, and a hiring recommendation — all stored on the applicant record without leaving Odoo.

يضيف تحليل مطابقة السير الذاتية بالذكاء الاصطناعي إلى التوظيف في أودو. ارفع السيرة الذاتية، اضغط تحليل، واحصل على درجة مطابقة رقمية وتفصيل للمزايا والثغرات وتوصية التوظيف — كل ذلك محفوظ على سجل المتقدم دون مغادرة أودو.

🤖

AI CV Analysis

Triggered from the applicant form via an "Analyse CV" button. The module extracts text from the attached CV (PDF via pdfminer, DOCX via python-docx), combines it with the job position description, and sends a structured prompt to the configured Odoo AI agent. The AI response is parsed and stored as era_cv_match_score and era_cv_analysis_html fields on the applicant record.

تحليل السيرة الذاتية بالذكاء الاصطناعي

يُشغَّل من نموذج المتقدم بزر "تحليل السيرة الذاتية". تستخرج الوحدة النص من السيرة المرفقة (PDF عبر pdfminer، DOCX عبر python-docx)، تجمعه مع وصف الوظيفة، وترسل موجّهاً منظَّماً لوكيل AI أودو. يُحلَّل الرد ويُخزَّن في حقلي era_cv_match_score وera_cv_analysis_html.

📊

Match Score (0–100)

The AI returns a numeric score reflecting how well the candidate's experience, skills, and qualifications align with the job requirements. The score appears as a progress-bar badge on the applicant kanban card and list view so recruiters can rank at a glance. Colour coding: green above 70, amber 40–70, red below 40.

درجة المطابقة (0–100)

يُعيد الذكاء الاصطناعي درجة رقمية تعكس مدى توافق خبرة المرشح ومهاراته ومؤهلاته مع متطلبات الوظيفة. تظهر الدرجة كشريط تقدم في بطاقة كانبان وعرض القائمة. تمييز لوني: أخضر فوق 70، عنبري 40–70، أحمر أقل من 40.

💪

Strengths & Gaps Breakdown

The analysis HTML includes two structured lists: Strengths (where the candidate clearly meets or exceeds requirements) and Gaps (missing skills, insufficient experience, or unclear fit). Each point references specific text from the CV and the job description so recruiters can verify the AI's reasoning.

تفصيل المزايا والثغرات

يتضمن HTML التحليلي قائمتين منظمتين: المزايا (أين يلبّي المرشح المتطلبات أو يتجاوزها) والثغرات (المهارات المفقودة أو الخبرة غير الكافية). كل نقطة تستشهد بنص محدد من السيرة الذاتية والوصف الوظيفي.

📝

Hiring Recommendation

A one-paragraph AI summary recommends whether to advance the candidate to the next stage, request a screening call, or decline — with brief reasoning. The recruiter can accept or override the recommendation; the AI note remains in the chatter for audit purposes.

توصية التوظيف

ملخص AI بفقرة واحدة يوصي بالتقدم للمرحلة التالية أو طلب مقابلة أولية أو الرفض — مع مبرر موجز. يمكن للمجنّد قبول التوصية أو تجاوزها؛ تبقى ملاحظة AI في السجل للمراجعة.

⚡

Bulk Analysis Action

A server action on the applicant list allows selecting multiple applicants and running AI analysis on all of them in a background job. A progress counter shows how many have been processed and how many remain, updating every 30 seconds.

إجراء التحليل الجماعي

إجراء خادم في قائمة المتقدمين يتيح اختيار متعددين وتشغيل تحليل AI عليهم في وظيفة خلفية. عداد تقدم يُظهر كم جرى تحليله وكم تبقى، يُحدَّث كل 30 ثانية.

🎯

Job-Description Aware

The analysis is anchored to the actual hr.job or hr.applicant.category description on the recruitment position — not a generic rubric. Changing the job description changes what the AI evaluates, so the analysis always reflects the current requirements and no two job analyses use the same rubric.

مرتبط بالوصف الوظيفي

يستند التحليل إلى الوصف الفعلي للوظيفة في hr.job أو hr.applicant.category — لا معيار عام. تغيير الوصف الوظيفي يغيّر ما يقيّمه الذكاء الاصطناعي، فلا تحليلان لوظيفتين يستخدمان نفس المعيار.

How It Works · كيف يعمل

  1. Recruiter posts a job position with a detailed description and requirements
  2. Applicant applies and attaches their CV (PDF or DOCX)
  3. Recruiter opens the applicant form and clicks "Analyse CV"
  4. AI reads CV vs job description, returns score + breakdown + recommendation (stored on record)
  5. Score appears on kanban card; recruiter reviews analysis HTML and decides next stage
  6. Bulk action processes multiple applicants in background overnight
  1. يُنشر منصب وظيفي بوصف تفصيلي ومتطلبات
  2. يتقدم مرشح ويرفق سيرته الذاتية (PDF أو DOCX)
  3. يفتح المجنّد نموذج المتقدم ويضغط "تحليل السيرة الذاتية"
  4. يقرأ الذكاء الاصطناعي السيرة مقابل الوصف الوظيفي ويُعيد درجة + تفصيل + توصية
  5. تظهر الدرجة في بطاقة كانبان ويراجع المجنّد التحليل
  6. الإجراء الجماعي يعالج متقدمين متعددين في الخلفية

⚡ Works with Any Odoo AI Provider

The CV analysis uses whichever AI provider and model is configured on the ERA AI agent — OpenAI GPT-4o, Claude, Gemini, or a local model via era_odoo_ai_ext. No hardcoded provider dependency.

يستخدم تحليل السيرة أي مزوّد AI مُكوَّن على وكيل ERA — OpenAI GPT-4o أو Claude أو Gemini أو نموذج محلي عبر era_odoo_ai_ext. لا يوجد ارتباط بمزوّد محدد.
