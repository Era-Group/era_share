ERA Enrich Base

The shared foundation for all ERA Enrich add-ons — manages the API connection, rate limits, callback endpoints, and configuration settings used by CRM and Recruitment enrichment modules.

ERA Enrich — الموديول الأساسي

يوفّر هذا الموديول البنية التحتية المشتركة لجميع إضافات ERA Enrich، بما فيها عميل API، وإعدادات الاتصال، وعناوين الاستجابة اللاتزامنية (Callbacks)، وضوابط حدّ المعدّل. ثبّته أولاً قبل أي إضافة أخرى من مجموعة Enrich، سواء كانت CRM أو التوظيف. يدير الرابط الوكيل مع خدمة Era Enrich ويضمن إجراء الطلبات بشكل آمن دون تجاوز حدود الاستخدام.

🔌

Shared API Client

Centralises the connection to the Era Enrich service — one place to configure the proxy URL, credentials, and timeouts for all dependent modules.

⏱️

Rate Limit Controls

Enforces per-minute and bulk request caps so enrichment jobs run safely in the background without overwhelming the API or triggering throttling.

📡

Callback Endpoints

Exposes secure webhook endpoints so the Era Enrich service can post results back asynchronously — no polling required.

⚙️

Settings UI

A dedicated settings section in Odoo lets admins configure the API URL, token, and rate-limit thresholds — all without touching code.
