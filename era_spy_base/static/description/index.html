ERA Enrich Base

القاعدة الأساسية لـ ERA Enrich

The shared infrastructure module that all ERA Enrich add-ons depend on. It manages HTTP connections, stores credentials securely, enforces rate limits, exposes async callback endpoints, and provides a settings UI — so higher-level modules need no plumbing of their own.

الوحدة الأساسية المشتركة التي تعتمد عليها جميع إضافات ERA Enrich. تدير اتصالات HTTP وتخزّن بيانات الاعتماد بأمان وتُطبّق حدود المعدل وتُعرّض نقاط نهاية استدعاء رجعي غير متزامن — فلا تحتاج الوحدات العليا لأي تمديدات تحتية.

🔌

Shared HTTP Client

A Python class EraEnrichClient wraps requests.Session with base URL, bearer token auth, retry logic (3 retries with exponential backoff), and a configurable timeout. All ERA Enrich modules import and instantiate this class — one implementation, zero duplication across the suite.

عميل HTTP مشترك

فئة Python EraEnrichClient تلفّ requests.Session بعنوان URL الأساسي وتوثيق bearer وإعادة المحاولة (3 محاولات بتراجع أسي) ومهلة قابلة للضبط. جميع وحدات ERA Enrich تستورد هذه الفئة — تنفيذ واحد وصفر تكرار عبر المجموعة.

⏱️

Rate Limit Controls

Two configurable limits: era_enrich.rpm_limit (requests per minute, default 60) and era_enrich.bulk_max (max records per bulk job). A token-bucket counter in Odoo's in-memory cache enforces the per-minute cap across all workers, preventing API throttling from the enrichment service.

ضوابط حد المعدل

حدان قابلان للضبط: era_enrich.rpm_limit (طلبات في الدقيقة، الافتراضي 60) وera_enrich.bulk_max (أقصى سجلات للوظيفة الجماعية). عداد دلو رمزي في ذاكرة أودو يُطبّق الحد عبر جميع العمّال، مما يمنع تقييد API من خدمة الإثراء.

📡

Async Callback Endpoints

Exposes /era_enrich/callback/<token> as a public JSON endpoint. The Era Enrich service POSTs enrichment results back to this URL after processing. The controller validates the token, finds the originating record, and writes the result — no polling, no open long-lived connections, no webhook delays.

نقاط نهاية الاستدعاء الرجعي غير المتزامن

تُعرّض /era_enrich/callback/<token> كنقطة نهاية JSON عامة. تُرسل خدمة Era Enrich نتائج الإثراء عبر POST لهذا العنوان بعد المعالجة. يُتحقق المتحكم من الرمز، يجد السجل الأصلي، ويكتب النتيجة — بلا استطلاع ولا اتصالات مفتوحة مطوّلة.

⚙️

Settings UI

A dedicated section in Settings → ERA Group → Enrich lets admins set the API base URL, bearer token, RPM limit, and bulk cap without touching system parameters or code. All settings changes take effect immediately and are reflected in the next API call.

واجهة الإعدادات

قسم مخصص في الإعدادات ← مجموعة ERA ← Enrich يتيح للمسؤولين ضبط عنوان URL الأساسي ورمز bearer وحد RPM والحد الجماعي دون لمس معاملات النظام أو الكود. جميع التغييرات تسري فوراً وتنعكس في استدعاء API التالي.

🏗️

Foundation for Extensions

era_spy_crm and era_spy_recruitment both list era_spy_base in their depends. Install this module first; the extensions automatically gain the shared client, rate-limiter, and callback infrastructure without any additional configuration.

قاعدة للامتدادات

تدرج era_spy_crm وera_spy_recruitment كلتاهما era_spy_base في قائمة depends. ثبِّت هذه الوحدة أولاً؛ تكتسب الامتدادات تلقائياً العميل المشترك ومُقيّد المعدل وبنية الاستدعاء الرجعي دون أي تكوين إضافي.

How It Works · كيف يعمل

  1. Install era_spy_base
  2. Set API URL and bearer token in Settings → ERA Enrich
  3. Set RPM and bulk limits as needed
  4. Install era_spy_crm and/or era_spy_recruitment
  5. They use EraEnrichClient automatically — no additional setup
  6. Enrichment results arrive via the callback URL and are written to records in real time
  1. ثبِّت era_spy_base
  2. اضبط عنوان API ورمز bearer في الإعدادات ← ERA Enrich
  3. اضبط حدود RPM والجملة حسب الحاجة
  4. ثبِّت era_spy_crm و/أو era_spy_recruitment
  5. تستخدمان EraEnrichClient تلقائياً — دون إعداد إضافي
  6. تصل نتائج الإثراء عبر عنوان الاستدعاء الرجعي وتُكتب في السجلات فوراً

🔑 Install Once, Use Everywhere

era_spy_base is a technical dependency — install it once and every ERA Enrich extension shares the same credentials, rate limits, and callback infrastructure without any additional setup. Uninstalling an extension does not affect the base or other extensions.

era_spy_base تبعية تقنية — ثبِّتها مرة واحدة وكل امتداد ERA Enrich يشارك نفس بيانات الاعتماد وحدود المعدل وبنية الاستدعاء الرجعي دون إعداد إضافي. إلغاء تثبيت امتداد لا يؤثر على القاعدة أو الامتدادات الأخرى.
