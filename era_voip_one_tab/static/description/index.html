ERA VoIP One Tab

Connect SIP only on call and keep a single registered tab — prevents duplicate SIP registrations.

نظرة عامة

تحلّ هذه الوحدة مشكلة تسجيل SIP المتعدد عند فتح أودو في عدة تبويبات، إذ تضمن بقاء تبويب واحد فقط مسجلًا في كل وقت. يتم الاتصال بخادم SIP عند الحاجة للمكالمة فقط بدلًا من الاتصال الدائم عند تحميل الصفحة. هذا يمنع تعدد الرنين ويقلل استهلاك الموارد بشكل ملحوظ.

Key Features

🔌

Single Tab SIP

Ensures only one browser tab is registered with the SIP server at a time — eliminates the duplicate registration problem when Odoo is open in multiple tabs.

⚡

Connect on Call

SIP connection is established only when a call is being made — not on page load — reducing unnecessary persistent connections and resource usage.

🚫

No Duplicate Rings

With a single registration, incoming calls ring in exactly one tab — no more multiple phones ringing simultaneously confusing agents.

🛡️

Lightweight Patch

A minimal, non-invasive extension to Odoo's VoIP module — no vendor code modified, compatible with future VoIP updates.
