ERA VoIP One Tab

Connect SIP only when a call is active and keep a single registered browser tab — eliminates duplicate SIP registrations, ghost calls, and missed ring notifications when multiple tabs are open.

ERA VoIP — تسجيل تبويب واحد

يحلّ هذا الموديول مشكلة تسجيل SIP المزدوج عند فتح أودو في عدة تبويبات في نفس المتصفح. يربط الاتصال بـ SIP فقط عند وجود مكالمة نشطة، ويضمن أن تبويباً واحداً فقط هو المسجَّل في أي وقت، ما يمنع المكالمات الوهمية وفوات الرنين وتعارض الأصوات. لا يحتاج إلى أي إعداد — ثبّته ويعمل فوراً.

🎯

Single Registered Tab

Only one browser tab holds a SIP registration at a time — other tabs detect the active one and stay idle, preventing duplicate REGISTER storms.

📵

Connect on Call Only

SIP connects when a call starts and disconnects when it ends — no persistent socket kept alive in every idle tab.

🔇

No Ghost Calls

Duplicate registrations cause unanswered ghost rings in background tabs — this module eliminates them entirely.

⚡

Zero Config

Install and it works — no settings page needed. A configurable permission controls who benefits from the one-tab mode.

ERA Group · Odoo 19 · Requires voip
