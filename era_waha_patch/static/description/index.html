ERA WAHA Patch

رقعة WAHA من ERA

A thin, update-safe patch layer that sits on top of sadeem_waha_whatsapp and silences JavaScript console errors and UI glitches introduced by Odoo 19 compatibility gaps — zero vendor file modifications, zero residual changes on uninstall.

طبقة رقع رفيعة وآمنة عند التحديث تعمل فوق sadeem_waha_whatsapp وتُصمت أخطاء JavaScript وعيوب واجهة المستخدم الناتجة عن فجوات توافق أودو 19 — لا تعديلات على ملفات البائع، ولا تغييرات متبقية عند إلغاء التثبيت.

🩹

Wizard View Chat Button Patch

sadeem_waha_whatsapp renders a "Chat" button in certain wizard views using a component reference whose internal path changed between Odoo minor versions.

The patch wizard_view_chat_button_patch.js updates the component lookup to the current Odoo 19 path, eliminating a Cannot read properties of undefined JavaScript error that fired in the browser console on every wizard open — without touching the vendor file at all.

رقعة زر الدردشة في عرض المعالج

تُعرض sadeem_waha_whatsapp زر "دردشة" في بعض عروض المعالج باستخدام مرجع مكوّن تغيّر مساره الداخلي بين إصدارات أودو الثانوية. تُحدّث الرقعة البحث عن المكوّن إلى مسار أودو 19 الحالي، مما يزيل خطأ JavaScript Cannot read properties of undefined الذي يظهر عند كل فتح لمعالج — دون لمس ملف البائع.

⚠️

Notification Service Patch

The whatsapp_notification_service.js in sadeem_waha_whatsapp called a legacy bus.service method removed in Odoo 19.0.x.

The patch wraps the call in a try/catch and falls back to the new bus API, stopping a recurring TypeError from polluting logs and potentially blocking unrelated notification handlers that come after it in the event chain.

رقعة خدمة الإشعارات

استدعت whatsapp_notification_service.js طريقة bus.service قديمة أُزيلت في أودو 19.0.x. تُغلّف الرقعة الاستدعاء في try/catch وتتراجع إلى واجهة bus الجديدة، مما يوقف TypeError المتكرر عن تلويث السجلات وربما إعاقة معالجات إشعارات غير ذات صلة تأتي بعده في سلسلة الأحداث.

🔄

Update-Safe Architecture

Both patches use Odoo's standard patch(ComponentClass, { ... }) utility imported from @web/core/utils/patch. The patch targets each component class by its import path, not by monkey-patching the module object.

When sadeem_waha_whatsapp releases an update, only the component class signatures need checking — the patch infrastructure itself is intact and rarely breaks on a vendor bump.

بنية آمنة عند التحديث

تستخدم كلتا الرقعتين أداة أودو القياسية patch(ComponentClass, { ... }) المستوردة من @web/core/utils/patch. تستهدف الرقعة كل فئة مكوّن بمسار استيرادها لا بتعديل كائن الوحدة مباشرة، لذا عند تحديث sadeem_waha_whatsapp تحتاج فقط للتحقق من توقيعات فئة المكوّن — بنية الرقعة نفسها سليمة ونادراً ما تنكسر.

🚫

No Vendor File Modifications

sadeem_waha_whatsapp's JavaScript, Python, and XML files are completely untouched. Installing this patch module alongside the vendor module is safe for any Odoo upgrade path.

Uninstalling it reverts to the original warning-producing behaviour with no residual changes left behind — the vendor module continues to function exactly as the vendor shipped it.

لا تعديلات على ملفات البائع

ملفات JavaScript وPython وXML الخاصة بـ sadeem_waha_whatsapp غير ملموسة تماماً. تثبيت وحدة الرقعة هذه جنباً إلى جنب مع وحدة البائع آمن لأي مسار ترقية أودو. إلغاء تثبيتها يُعيد السلوك الأصلي المنتج للتحذيرات دون تغييرات متبقية — وحدة البائع تستمر في العمل كما أُرسلت.

🧹

Clean Browser Console

The patches reduce console noise to zero for the patched paths. In production environments, a clean browser console is important: monitoring tools that parse console output for errors will no longer fire false alerts from the WhatsApp integration.

Developers debugging unrelated issues can work without the distraction of recurring TypeError entries.

وحدة تحكم متصفح نظيفة

يُقلّل الرقع ضوضاء وحدة التحكم إلى الصفر للمسارات المُرقَّعة. في بيئات الإنتاج، تُصبح وحدة التحكم النظيفة مهمة: أدوات المراقبة التي تحلل وحدة التحكم لن تُطلق تنبيهات كاذبة من تكامل WhatsApp. المطورون الذين يشخّصون مشاكل غير ذات صلة يعملون دون تشتيت إدخالات TypeError المتكررة.

📦

Lightweight Module

The entire patch layer is two JavaScript files totalling under 60 lines of code and zero new Python models, zero new database tables, and zero new XML views.

Install time is under a second and the module has no impact on Odoo startup time or memory footprint. Uninstalling removes it cleanly with no traces.

وحدة خفيفة الوزن

طبقة الرقع بأكملها ملفان JavaScript بإجمالي أقل من 60 سطر كود وصفر نماذج Python جديدة وصفر جداول قاعدة بيانات وصفر عروض XML جديدة. وقت التثبيت أقل من ثانية والوحدة لا تؤثر على وقت إطلاق أودو أو بصمة الذاكرة. إلغاء التثبيت يُزيلها بنظافة دون أثر.

How it works

  1. Install sadeem_waha_whatsapp from the vendor (standard process).
  2. Install era_waha_patch alongside it — no extra configuration needed.
  3. Next browser reload includes the patch JS files in web.assets_backend.
  4. Patches apply silently at runtime — wizard views open without JS errors; notification service falls back cleanly to the new bus API.
  5. When sadeem_waha_whatsapp updates, re-test the two patched paths and bump era_waha_patch version only if the component signatures changed.

كيف يعمل

  1. ثبّت sadeem_waha_whatsapp من البائع (الإجراء المعتاد).
  2. ثبّت era_waha_patch إلى جانبه — لا تهيئة إضافية مطلوبة.
  3. إعادة تحميل المتصفح التالية تتضمن ملفات JS للرقعة في web.assets_backend.
  4. تُطبَّق الرقع بصمت في وقت التشغيل — تفتح عروض المعالج بلا أخطاء JS؛ خدمة الإشعارات تتراجع بنظافة إلى واجهة bus الجديدة.
  5. عند تحديث sadeem_waha_whatsapp، أعد اختبار المسارين المرقّعين وارفع إصدار era_waha_patch فقط إذا تغيّرت توقيعات المكوّن.

📋 Dependency

This module has a hard dependency on sadeem_waha_whatsapp — it cannot be installed without it. If the vendor module is uninstalled, this patch module must be uninstalled first. It does not add any new models, views, or security groups of its own.

هذه الوحدة تعتمد اعتماداً صارماً على sadeem_waha_whatsapp — لا يمكن تثبيتها بدونها. إذا أُزيلت وحدة البائع، يجب إلغاء تثبيت هذه الرقعة أولاً. لا تُضيف أي نماذج أو عروض أو مجموعات أمان خاصة بها.

ℹ️ Console-clean deployments

Repeated JavaScript errors in the browser console are not merely aesthetic — they can mask real errors, slow down DevTools, and confuse monitoring tools that scan console output. Keeping the console clean is a production-quality standard, and this module enforces it for the WhatsApp integration without waiting for the vendor to patch upstream.

أخطاء JavaScript المتكررة في وحدة تحكم المتصفح ليست مجرد مسألة جمالية — يمكنها إخفاء أخطاء حقيقية وإبطاء DevTools وإرباك أدوات المراقبة التي تفحص مخرجات وحدة التحكم. إبقاء وحدة التحكم نظيفة معيار جودة إنتاج، وهذه الوحدة تفرضه لتكامل WhatsApp دون انتظار البائع.
