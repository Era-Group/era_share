ERA Website Voice Agent AI

A floating voice widget on your website that lets visitors speak to an OpenAI Realtime agent — records calls, generates Arabic summaries, and stores transcripts and recordings directly in Odoo CRM.

وكيل صوتي ذكي للموقع من ERA

يضيف هذا الموديول زراً عائماً على موقعك الإلكتروني يتيح للزوار التحدث مباشرة مع وكيل ذكاء اصطناعي صوتي (OpenAI Realtime)، مع تسجيل المكالمة ونسخها وإنشاء ملخص عربي تلقائي وحفظه في CRM. مثالي لالتقاط العملاء المحتملين عبر الصوت وتوثيق المحادثات دون تدخل يدوي. يشمل واجهة إعداد كاملة في الإعدادات، ومتابعة محادثات الصوت في CRM.

🎙️

Realtime Voice Widget

A floating mic button on your website connects visitors to an OpenAI Realtime agent via WebRTC — low-latency, natural conversation in real time.

📝

Auto Transcription

Calls are transcribed automatically and stored with the CRM record — full conversation history is available without any manual note-taking.

🇸🇦

Arabic AI Summaries

After each call the AI generates a concise Arabic summary — customer intent, key questions, and next steps — saved directly on the CRM lead.

📂

Recordings in CRM

Audio recordings are attached to the CRM lead for compliance and quality review — scoped to the Realtime widget, not all calls.

⚙️

Easy Configuration

Configure the OpenAI API key, voice model, and agent instructions from Odoo settings — no code changes required to customise the agent's persona.

ERA Group · Odoo 19 · Requires OpenAI Realtime API access
