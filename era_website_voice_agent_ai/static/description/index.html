ERA Website Voice Agent AI

وكيل صوتي ذكي للموقع من ERA

Add a floating microphone button to your Odoo website that connects visitors to an OpenAI Realtime API voice agent in real time — conversations are transcribed, summarised in Arabic, and stored as qualified CRM leads with full recordings, automatically.

أضف زر ميكروفون عائم إلى موقع أودو يُوصّل الزوار بوكيل صوتي يعمل بـ OpenAI Realtime API في الوقت الفعلي — تُنسخ المحادثات وتُلخَّص بالعربية وتُحفظ كـفرص CRM مؤهّلة مع تسجيلات كاملة، تلقائياً.

🎙️

Realtime Voice Widget

A floating circular mic button (configurable position, bottom-right by default) is injected into the website frontend via a QWeb template override. Clicking it opens a WebRTC audio channel directly to the OpenAI Realtime API.

The widget displays a live waveform animation during the conversation and a clear "Listening…" / "AI is speaking…" status indicator so visitors always know what is happening.

أداة صوتية حية

يُحقن زر ميكروفون دائري عائم (موقعه قابل للتهيئة، أسفل اليمين افتراضياً) في واجهة الموقع عبر تجاوز قالب QWeb. الضغط عليه يفتح قناة صوت WebRTC مباشرةً مع OpenAI Realtime API. تعرض الأداة رسوماً متحركة للموجة الصوتية الحية أثناء المحادثة ومؤشر حالة واضح "يستمع…" / "الذكاء الاصطناعي يتحدث…".

🤖

OpenAI Realtime Agent

The agent's persona, system prompt, voice model (Alloy, Echo, Shimmer, or Verse), and allowed tools are fully configured from Odoo Settings → Website → Voice Agent.

The agent speaks and understands Arabic, English, or both — controlled by the voice_agent_language system parameter. No code editing is needed to change the agent's behaviour or language after initial setup.

وكيل OpenAI الحي

شخصية الوكيل وموجّه النظام ونموذج الصوت (Alloy، Echo، Shimmer، أو Verse) والأدوات المسموح بها تُهيَّأ بالكامل من إعدادات أودو. يتحدث الوكيل ويفهم العربية أو الإنجليزية أو كليهما — يتحكم به معامل النظام voice_agent_language. لا تعديل كود مطلوب لتغيير سلوك الوكيل أو لغته بعد الإعداد الأولي.

📝

Automatic Transcription

The full conversation — visitor and agent turns alike — is transcribed in real time via the Realtime API's text delta events. The transcript is stored as an era.realtime.call.transcript record with speaker labels, timestamps, and the full turn-by-turn text.

Transcripts are linked to the resulting CRM lead and are searchable from the back-end lead view.

نسخ تلقائي

تُنسخ المحادثة الكاملة — دور الزائر والوكيل معاً — في الوقت الفعلي عبر أحداث نص دلتا لـ Realtime API. يُحفظ النص كسجل era.realtime.call.transcript مع تسميات المتحدث والطوابع الزمنية والنص الكامل دوراً بدور. تُربط النصوص بفرصة CRM الناتجة وتكون قابلة للبحث من عرض الفرصة في الخلفية.

🇸🇦

Arabic AI Summary

After the call ends, a second AI call (standard chat API, not Realtime) generates a concise Arabic summary covering: customer intent, key questions asked, objections raised, and the recommended next step for the sales team.

The summary is written to the CRM lead description and a dedicated era_voice_summary_ar field, so Arabic-speaking sales teams get an immediately actionable brief.

ملخّص عربي بالذكاء الاصطناعي

بعد انتهاء المكالمة، يولّد استدعاء AI ثانٍ (واجهة الدردشة القياسية) ملخصاً عربياً موجزاً يتضمن: نية العميل، الأسئلة الرئيسية المطروحة، الاعتراضات المُثارة، والخطوة التالية الموصى بها لفريق المبيعات. يُكتب الملخص في وصف فرصة CRM وحقل era_voice_summary_ar المخصص.

📂

Recording Storage

Browser-side MediaRecorder captures the audio stream in WebM/Opus format throughout the call. On call end, the recording is uploaded to Odoo as an ir.attachment and linked directly to the CRM lead.

Recordings can be played back from the lead chatter at any time, and the file size is capped via the voice_agent_max_recording_mb system parameter to keep storage usage predictable.

تخزين التسجيلات

يلتقط MediaRecorder على جانب المتصفح تدفق الصوت بصيغة WebM/Opus طوال المكالمة. عند انتهاء المكالمة، يُرفع التسجيل إلى أودو كـ ir.attachment ويُربط مباشرةً بفرصة CRM. يمكن تشغيل التسجيلات من السجل الصوتي للفرصة في أي وقت، وحجم الملف مقيّد عبر معامل نظام voice_agent_max_recording_mb.

📊

Automatic CRM Lead Creation

If no matching partner is found by email or phone, a new CRM lead is created automatically with: the lead name set to the AI-extracted visitor name (or "Website Voice Call — {date}" as a fallback), the description filled with the Arabic summary, and the tag "Voice Agent" applied.

The lead appears in the standard CRM pipeline immediately — ready for follow-up without any manual data entry.

إنشاء فرصة CRM تلقائي

إذا لم يُعثر على شريك مطابق بالبريد الإلكتروني أو الهاتف، تُنشأ فرصة CRM جديدة تلقائياً: اسم الفرصة مستخرج بالذكاء الاصطناعي من اسم الزائر (أو "مكالمة صوتية من الموقع — {التاريخ}" احتياطياً)، الوصف يتضمن الملخص العربي، والوسم "Voice Agent" مطبّق. تظهر الفرصة في خط أنابيب CRM فوراً — جاهزة للمتابعة دون إدخال بيانات يدوي.

⚙️

Full Settings Page

A dedicated settings section under Settings → Website → Voice Agent lets admins configure: OpenAI API key, voice model selection, agent persona/system-prompt text, widget position on the page, primary language, recording on/off toggle, and the CRM pipeline stage for newly created leads.

All changes take effect immediately without any code deployment or server restart.

صفحة إعدادات كاملة

قسم إعدادات مخصص تحت الإعدادات → الموقع → الوكيل الصوتي يُمكّن المديرين من ضبط: مفتاح OpenAI API، اختيار نموذج الصوت، نص شخصية الوكيل/موجّه النظام، موقع الأداة في الصفحة، اللغة الأساسية، تفعيل/إلغاء التسجيل، ومرحلة خط أنابيب CRM للفرص الجديدة. جميع التغييرات فورية دون نشر كود أو إعادة تشغيل خادم.

How it works

  1. Configure OpenAI API key and agent settings in Settings → Website → Voice Agent.
  2. Website visitor clicks the floating mic button → WebRTC session opens with OpenAI Realtime API.
  3. Conversation happens in real time; transcript accumulates turn by turn.
  4. Call ends → browser uploads the WebM/Opus recording to Odoo as an attachment.
  5. AI generates an Arabic summary of the conversation (intent, questions, objections, next step).
  6. CRM lead is created with transcript + recording + Arabic summary → sales team picks it up in the pipeline.

كيف يعمل

  1. هيّئ مفتاح OpenAI API وإعدادات الوكيل في الإعدادات → الموقع → الوكيل الصوتي.
  2. يضغط زائر الموقع على زر الميكروفون العائم → تفتح جلسة WebRTC مع OpenAI Realtime API.
  3. تجري المحادثة في الوقت الفعلي؛ يتراكم النص دوراً بدور.
  4. تنتهي المكالمة → يرفع المتصفح تسجيل WebM/Opus إلى أودو كمرفق.
  5. يولّد الذكاء الاصطناعي ملخصاً عربياً (النية، الأسئلة، الاعتراضات، الخطوة التالية).
  6. تُنشأ فرصة CRM مع النص + التسجيل + الملخص العربي → يلتقطها فريق المبيعات في خط الأنابيب.

🔑 API key required

An OpenAI API key with access to the Realtime API (gpt-4o-realtime-preview or newer) is required. Standard chat completions access is additionally needed for the post-call Arabic summary step. The key is stored encrypted in Odoo system parameters and never exposed to the browser frontend.

يُطلب مفتاح OpenAI API مع صلاحية الوصول إلى Realtime API (gpt-4o-realtime-preview أو أحدث). الوصول إلى اكتمالات الدردشة القياسية مطلوب أيضاً لخطوة الملخص العربي بعد المكالمة. المفتاح مُخزَّن مشفّراً في معاملات نظام أودو ولا يُكشف أبداً لواجهة المتصفح الأمامية.

ℹ️ Browser permissions

The floating widget requests microphone permission via the standard browser getUserMedia API — the browser's native permission prompt will appear the first time the visitor clicks the mic button. HTTPS is required for getUserMedia to work; the module is designed for production Odoo websites served over TLS.

تطلب الأداة العائمة إذن الميكروفون عبر واجهة المتصفح القياسية getUserMedia — يظهر موجّه إذن المتصفح الأصلي في المرة الأولى التي يضغط فيها الزائر على زر الميكروفون. HTTPS مطلوب لعمل getUserMedia؛ الوحدة مصممة لمواقع أودو الإنتاجية المخدومة عبر TLS.
