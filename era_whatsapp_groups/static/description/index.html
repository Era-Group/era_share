WhatsApp Groups for Odoo

Group conversations over Meta's official Cloud API, inside Discuss

مجموعات واتساب داخل أودو

محادثات المجموعات عبر واجهة ميتا الرسمية، داخل Discuss

Odoo's standard WhatsApp module talks to one number at a time. This module adds group conversations on the same official Cloud API — no unofficial client, no companion device, no ban risk of that kind. Groups are discovered from Meta and stay disabled until an operator approves each one.

وحدة واتساب القياسية في أودو تتحدث مع رقم واحد في كل مرة. هذه الوحدة تضيف محادثات المجموعات على نفس الواجهة الرسمية — بلا عميل غير رسمي وبلا جهاز مرافق. تُكتشف المجموعات من ميتا وتبقى معطّلة حتى يعتمدها المشغّل واحدة واحدة.

✅

Approve before you listen

الاعتماد قبل الاستماع

Sync discovers groups; it never enables one. An unapproved group's messages are dropped, not channelled.

المزامنة تكتشف ولا تفعّل. رسائل أي مجموعة غير معتمدة تُهمَل ولا تُنشئ قناة.

👤

Real senders, not one blob

كاتب الرسالة الحقيقي

Each inbound group message is attributed to the participant who actually wrote it.

كل رسالة واردة تُنسب إلى المشارك الذي كتبها فعلاً لا إلى المجموعة ككل.

🔀

Runs beside WAHA

يعمل بجانب واحة

Cloud API and WAHA accounts are routed independently and never cross. Covered by a dedicated regression suite.

حسابات الواجهة الرسمية وحسابات واحة تُوجَّه بشكل مستقل ولا تتقاطع، مع اختبارات مخصصة لذلك.

Before you install — eligibility

قبل التثبيت — الأهليّة

1. The number must be an Official Business Account. An ineligible number answers every group call with error 131215.

١. يجب أن يكون الرقم حساب أعمال رسمي (OBA). الرقم غير المؤهّل يرد على كل استدعاء للمجموعات بالخطأ 131215.

2. Meta caps a group at 8 participants. Count your groups before planning a migration.

٢. ميتا تحدّد المجموعة بـ٨ مشاركين. عُدّ أعضاء مجموعاتك قبل التخطيط للانتقال.

3. Meta bills per delivered participant — one send into an 8-person group is 8 billed messages.

٣. ميتا تحاسب لكل مشارك — إرسالة واحدة لمجموعة من ٨ تعادل ٨ رسائل محاسَبة.
