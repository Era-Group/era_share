Main Features

Session Management

Create and manage multiple WhatsApp sessions with different phone numbers and configurations.

QR Code Integration

Scan QR codes directly from Odoo interface for quick and easy authentication.

Message Sending

Send text messages, files, images, and voice messages through WhatsApp API.

Template System

Create and use message templates for quick access to common messages and responses.

Contact Integration

Link WhatsApp communications with Odoo contacts for better relationship management.

Company Settings

Set default WhatsApp session per company for multi-company environments.

Message History

Track all sent and received messages with complete conversation history.

Webhook Support

Receive incoming messages and status updates through webhooks automatically.

Live Chat View

Open a real-time chat dialog directly from any form view or message record. Supports live message fetching from WAHA with auto-refresh every 5 seconds.

File Attachments in Chat

Send images, videos, audio, documents, and other files directly from the live chat dialog with inline preview before sending.

Session Message Counters

Smart buttons on the session form show accurate sent and received message counts, with one-click filtering to view only incoming or outgoing messages.
